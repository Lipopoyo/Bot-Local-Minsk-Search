# Bot [Local Minsk Search]

### Local Minsk Search

Telegram-бот на базе aiogram 3, который принимает от пользователя любое место, адрес или координаты в Минске, а в ответ присылает красивую cyber-map с картой этой точки. 

### Как это работает

1. Пользователь отправляет текстовый запрос (например, *«Немига»* или *«проспект Независимости, 20»*) либо делится геолокацией.
2. Бот через **Яндекс Геокодер** находит точные координаты места.
3. Через **Яндекс Static API** скачивается изображение карты.
4. Библиотека **Pillow** генерирует итоговую стилизованную карточку с HUD-элементами, названием места, координатами и временем запроса.

### Настройка и запуск

1. **Клонирование репозитория и переход в папку проекта:** 

git clone https://github.com/ваш_username/имя_репозитория.git
cd имя_репозитория

2. **Создание и активация виртуального окружения:** 

python -m venv .venv
# Для Windows (PowerShell):
.venv\Scripts\activate
# Для macOS / Linux:
source .venv/bin/activate

3. **Установка зависимостей:** 

pip install -r requirements.txt

4. **Запуск бота:** 

python bot.py

### Структура проекта

* bot.py — точка входа, запуск polling-процесса.
* config.py — загрузка и валидация переменных окружения из .env.
* handlers/ — обработка команд (/start, /help) и сообщений от пользователя.
* services/ — логика работы с API Яндекса и генерация изображений (Pillow).
* assets/fonts/ — шрифты, необходимые для отрисовки текста на карточке.
* assets/ - референсы для отрисовки
